Frequently asked questions

Common Questions & Answers

Does SpareEye work without internet?

Yes. Motion detection and local recording work offline. Only Telegram alerts need an internet connection.

Can I use a USB or network camera?

Yes. Plug in any standard USB webcam, or connect a network camera that offers an RTSP or HTTP stream address.

Do I need an account or email to use it?

No accounts, no email, no cloud logins. Telegram is optional and uses your own bot.

Does it start watching as soon as I install it?

No. You choose a camera and press Start watching. You can separately choose to have it start watching whenever it opens.

Which computers are supported?

Windows 10 and 11, Debian and Ubuntu packages, and other Linux distributions with the required system libraries. macOS is not currently supported.
