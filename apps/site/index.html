Frequently asked questions

Before you set it up.

Does SpareEye work without internet?

Motion detection and local recording do. Telegram alerts need an internet connection.

Can I use a USB or network camera?

Yes. SpareEye supports local USB cameras and network cameras that provide a compatible RTSP or HTTP stream address.

Do I need a Telegram account?

No. Telegram is optional. You can use the camera and local recordings without setting up alerts.

Does it watch as soon as I install it?

No. Choose a camera and press Start watching. You can separately choose to start monitoring when the app opens.

Which computers are supported?

Windows 10 and 11, Debian and Ubuntu packages, and other Linux distributions with the required system libraries. macOS is not currently supported.
